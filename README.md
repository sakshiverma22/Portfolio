# Sakshi Portfolio

A static, responsive personal portfolio website.

## Deploy

Upload the contents of this package to any static hosting provider such as GitHub Pages, Netlify, Vercel, Cloudflare Pages, or an ordinary web server.

- Keep `index.html` at the site root.
- Keep `styles.css`, `script.js`, `package.json`, and the `assets/` folder alongside it.
- No build command or backend is required for a basic static deployment.
- Configure your custom domain (`sakshiverma.dev`) in your hosting provider and update DNS at your domain registrar.

## Included

- Responsive single-page portfolio layout
- Background-removed portrait
- Contact details and social links
- Five project cards with GitHub/live-demo links
- Mobile navigation and reduced-motion support
